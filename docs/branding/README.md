# SnapTrade CLI icon

Use [`snaptrade-cli-icon.png`](snaptrade-cli-icon.png) for the OAuth consent screen. It is a 512 × 512 PNG with a dark terminal tile, teal prompt, and amber cursor. The vector source is [`snaptrade-cli-icon.svg`](snaptrade-cli-icon.svg); [`snaptrade-cli-icon-64.png`](snaptrade-cli-icon-64.png) shows how it reads at the consent screen's 64 px size.

The dashboard accepts PNG logos from 240 × 240 to 1024 × 1024 pixels under 2 MB. Its logo uploader updates the **customer profile logo**, which the OAuth consent screen uses for customer-owned apps. If that customer owns other apps, changing the profile logo will change their displayed branding too.
